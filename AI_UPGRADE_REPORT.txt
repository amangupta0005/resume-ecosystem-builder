2. FEATURES IMPLEMENTED
--------------------------------------------------------------------------------
A. HYBRID DETERMINISTIC + SEMANTIC JD MATCH (/api/ai/match)
   - Zero Arbitrary Scoring: Extracts exact technical keywords and libraries 
     against JD requirements via regex word boundary matching.
   - Composite ATS Match Score: 60% deterministic keyword match + 40% contextual 
     semantic depth.
   - Explainable Coverage: Explicitly shows Matched Skills, Missing Skills, 
     and Keyword Coverage Ratio (e.g., 18 / 23 | 78%).

B. CATEGORIZED SKILL GAP ANALYSIS
   - Classifies missing requirements into:
     * Critical: Core non-negotiable requirements for the role.
     * Important: Major technologies expected for seniority.
     * Nice-to-Have: Secondary tools and domain bonuses.
   - Status tagging distinguishes: "already_present", "missing", 
     "weakly_represented", and "potentially_relevant".
   - Ethical, actionable recommendations on highlighting authentic project work 
     without fabricating skills.

C. IN-EDITOR AI BULLET REFINEMENT (/api/ai/suggest)
   - Interactive action triggers inside BulletOverrideEditor.tsx:
     * Stronger Impact: Enhances engineering clarity, active voice, and outcomes.
     * Make Concise: Eliminates filler words while protecting tech keywords.
     * Action Verb: Enforces strong verbs (Architected, Engineered, Implemented).
     * Tailor to Domain: Contextualizes phrasing to the target domain.
   - Strict Anti-Fabrication Rule: LLM prompt explicitly forbids hallucinating 
     metrics, percentages, company names, titles, or unverified claims.

D. REDIS CACHING, RATE LIMITING & SECURITY
   - Deterministic Hash Caching: Indexed by SHA-256 (resumeConfigId + resumeHash + jdHash) 
     with a 6-hour Redis TTL to eliminate duplicate model queries.
   - Sliding Rate Limiter: 25 requests per 10 minutes per IP using Redis INCR & EXPIRE.
   - Prompt Injection Defense: Inputs are isolated within strict XML tags 
     (<job_description>, <original_bullet>) with instructions to ignore injection attempts.
   - Offline Fallback Engine: Gracefully falls back to a deterministic heuristic 
     engine if Redis or the LLM API is unavailable.

E. USER INTERFACE INTEGRATION
   - Interactive JobMatchModal.tsx launched from the "AI JD Match" button on 
     the resume configuration page.
   - Includes real-time scorecards, matched/missing tags, prioritized gaps, 
     loading states, and error handling.

4. API ENDPOINTS
--------------------------------------------------------------------------------
POST /api/ai/match
  - Input:  { resumeConfigId: string, jobDescription: string }
  - Output: { success: true, data: JdMatchResult, fromCache: boolean }
  - Limits: Minimum 50 chars, maximum 15,000 chars. IP rate-limited.

POST /api/ai/suggest
  - Input:  { resumeConfigId: string, bulletId?: string, currentText: string, action: string }
  - Output: { success: true, data: BulletSuggestionResult }
  - Limits: IP rate-limited.
